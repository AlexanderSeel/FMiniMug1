## FM-1 control concept

### Normal layer
- Encoder 1–4: four highlighted page parameters.
- Left/right page buttons: previous/next panel section.
- Keyboard: notes / sequence transpose.
- Play: sequencer start/stop.
- Pattern: sequence selection.
- Preset: factory/user patch selection.

### HOLD layer
- OSC: encoder 1–3 select 32'/16'/8'/4'/2'; encoder 4 fine-adjusts glide.
- CONTOUR: encoder 1–4 edit the filter contour while the normal layer edits loudness contour.
- MOD: encoder 1 chooses LOW/HIGH/LAST note priority; encoder 4 switches single-trigger/retrigger.
- Future Hold + keyboard: instant waveform assignments and performance macros.
- Future Hold + Play: tap tempo / clock source.
- Future Hold + Preset: save/copy/compare.
- Future Hold + Pattern: step record / clear / duplicate.

### FOCUS mode
Press an encoder to zoom one parameter to nearly full screen, show its graph/value/history and use the keyboard for coarse presets/ranges while the encoder provides fine control.

## Preset policy
Factory patches are original parameter sets inspired by recognizable categories of classic analog sounds. Do not copy proprietary preset books, commercial banks, artwork, logos, or patch sheets verbatim.

## Felucca integration notes
Felucca is the proven low-level FM-1 reference for `.fwsc` packaging, Web MIDI installation, flash persistence, USB audio/MIDI, ALNK0/I2S audio, the ST7789-class 240×240 display, and the FM-1's 11×6 input matrix with 27 note keys, 14 buttons and seven encoders. FMiniMug1 keeps these details behind `fm1_platform.h`; see `docs/FELUCCA_PORT.md` for the port map and safe bring-up order.

The first real-device target remains deliberately read-only with respect to flash: display, input diagnostics and audio bring-up come before any package/erase/write path.
